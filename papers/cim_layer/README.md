# Evidence for "The Grid's Own Language"

Everything behind the numbers in *The Grid's Own Language: A Common Information Model Layer for LLM Grid Assistants*
(A. Alcántara, I. Karampinis, S. Chatzivasileiadis; under review; preprint
[arXiv:2611.20026](https://arxiv.org/abs/2611.20026)): the record of every run, the analyses, and the scripts that made the paper's figure, case study and
measurements. Every run records the code commit it ran on (`manifest.json`).

| Folder | In the paper | What is in it |
|---|---|---|
| `runs/A-ontology/` | Experiment 1, Table III | 555 runs (37 network tasks × 3 variants × 5): one `.jsonl` per run under `runs/`, plus `runs.csv`, `checks.csv`, `analysis.md` |
| `runs/B-components/` | Experiment 2, Table IV | 2,112 runs (88 tasks × 8 variants × 3), same layout |
| `runs/E-raw-tables/` | Section V-A (raw tables) | 185 runs (37 network tasks × 5): the agent given the network's raw pandapower tables instead of the layer; `vs-A/analysis.md` compares it with Experiment 1 |
| `runs/C-injection-AB-fixed/` | Section V-C, Table V | Error injection on the 2,717 recorded answers with the answer checks as released; `findings-to-label.csv` holds every finding on the answers as written, with its label |
| `runs/C-injection-AB/` | Section V-C | The checks as they were during the runs, before their revision: `injection.md` (the summary), `findings-to-label.csv` (the 330 findings on the answers as written, labelled) and `heldout-figures.json` (the 40 false alarms set aside before the checks were revised) |
| `runs/D-case-study/` | Section IV | The case-study session: `transcript.md`, `session.jsonl`, `audit.json` |
| `case_study/run_case_study.py` | Section IV | Runs the case-study session |
| `figures/fig_case.py` | Fig. 2 | Draws the CIGRE network from the CIM layer (no AI model) |
| `scale/measure_scale.py`, `scale/scale.json` | Section V-D | The layer and the checks on networks up to 9,241 buses |
| `scale/raw_tables_size.py`, `scale/raw_tables_size.json` | Section V-A | Size of the raw tables, whole, on networks from 15 to 9,241 buses |
| `scale/oberrhein_layer.py`, `scale/oberrhein_layer.json` | Section V-D | The layer on pandapower's MV Oberrhein network: feeders, switch roles, and what each feeder's outage cuts off |
| `scale/cgmes_layer.py`, `scale/cgmes_layer.json` | Section V-D | The layer on CGMES models (pandapower's example; ENTSO-E's SmallGrid test model, sources in the script) |
| `task-catalogue.md` | Section V | Every task and its criteria, generated by `evaluation/catalogue.py` |

## Reproducing

From the repository root, with the environment in `environment.yml`:

```
python -m evaluation.ablation run ontology --repeats 5 --out <folder>      # Experiment 1 (calls the configured LLM)
python -m evaluation.ablation run components --repeats 3 --out <folder>    # Experiment 2 (calls the configured LLM)
python -m evaluation.ablation run raw_tables --only tables --repeats 5 --out <folder>   # raw tables (calls the configured LLM)
python -m evaluation.ablation analyse papers/cim_layer/runs/B-components   # re-grade the recorded runs (no LLM)
python -m evaluation.injection papers/cim_layer/runs/A-ontology papers/cim_layer/runs/B-components --out <folder>
python papers/cim_layer/scale/measure_scale.py
python papers/cim_layer/scale/raw_tables_size.py
python papers/cim_layer/scale/oberrhein_layer.py
python papers/cim_layer/scale/cgmes_layer.py <CGMES.zip> ...
```

Re-grading and error injection call no AI model and reproduce the tables from the records here.

CONDUCTOR and its CIM layer keep improving after the paper, and so do the answer checks: run with the current
code, the error injection grades the same recorded answers better than the paper reports (more of the answers
that follow a misleading name are flagged, fewer correct figures are). To reproduce the paper's numbers exactly,
check out the commit each run records in its `manifest.json`.

## Notes

- The raw-tables run was made on 4 Nov 2026, a day after Experiment 1, with the same criteria. Those criteria were
  written before this variant existed, and some correct answers in it are worded in ways they do not match: on IEEE 30,
  "the data do not identify any unit as wind or solar" where the criterion looks for "the network does not say"; the
  two circuit breakers named by what they switch, as the raw tables give them no name. Read by hand, about 20 of the
  53 criteria this variant missed are of this kind (about 3 of 9 for the full system, about 5 of 114 with no layer);
  counted as met, the shares would be about 98 % (full system), 90 % (raw tables) and 65 % (no layer). The paper
  reports the criteria as fixed.
- This folder had another name when the runs were made; the run manifests keep each command exactly as it was run,
  with the paths of the time.
- Earlier error-injection runs (on Experiment 1 alone, and on both experiments before a scorer fix) and the per-item
  results of `runs/C-injection-AB/` are not published: no number in the paper comes from them, and
  `evaluation.injection` re-creates them from the recorded runs.
- The isolated backends' server logs (`runs/*/backends/`) and the runs' scratch caches are not published: they hold
  repeated library warnings and local paths, and nothing in the paper is computed from them.
